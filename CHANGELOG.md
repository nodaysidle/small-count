# Changelog

All notable Small Count releases are documented here.

## [0.1.0] — 2026-08-27

### Added

- Native macOS menu-bar counter built with Swift 6, SwiftUI, AppKit, Observation, and SwiftData.
- Create, edit, record, local-day totals, archive, restore, and deterministic Markdown export.
- Failure-safe transactional state preservation and ordered SwiftData schema migration.
- Keyboard navigation, VoiceOver labels, semantic appearance, reduced-motion behavior, and retry recovery.
- macOS 26 Control Center lifecycle hardening with a scoped AppKit status-item fallback.
- Custom Small Count app icon, release `.app` packaging, verified DMG distribution, and SHA-256 checksum.

### Distribution

- Apple Silicon (`arm64`).
- Requires macOS 15 or later.
- Ad-hoc signed; not Apple-notarized.
